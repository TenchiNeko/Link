# License decision required

This repository does not currently contain a project license. It must not be treated as reusable open-source software until the owner adds one.

Two common options to consider:

- **MIT** — short and permissive; preserves the copyright and disclaimer notice.
- **Apache-2.0** — permissive, with an express patent license and more detailed notice requirements.

The owner should choose the intended license, confirm that all retained code may be distributed under it, add the canonical license text as `LICENSE`, and add any required third-party notices before making the repository public.
